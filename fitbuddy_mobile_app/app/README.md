# FitBuddy App Module

This is the Android application module.

Build from repository root:
- cd fitbuddy-tracker-8901/fitbuddy_mobile_app
- ./gradlew :app:build

Alternatively, from this folder:
- ../gradlew :app:build

Notes:
- This project uses the Declarative Gradle DSL (.dcl files). Compose is enabled via the module’s declarative configuration.
- If you see "gradlew: No such file or directory" ensure you are in the fitbuddy_mobile_app folder which contains the wrapper.
